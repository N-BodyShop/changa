ChaNGa SIMD Port: Benchmark Results
===================================

Source
------
Commit 06e7596 (ChaNGa-test/changa, branch master). Each variant was built
from that committed tree. Only the arch/float configure flags differ:

  ours_avx        --enable-arch=avx
  ours_sse2       --enable-arch=sse2
  ours_sse2_float --enable-arch=sse2 --enable-float

Suite: ChaNGa_benchmark/suite/run_suite.sh, 3 reps per test.
  Results: ChaNGa_benchmark/suite/results/final_committed.tsv
Baseline: changa fork (ChaNGa_FORK_AMF599/changa), fresh same-session rerun.
  Results: ChaNGa_benchmark/suite/results/fork_latest.tsv

Machine load was 4 to 6 during the final run, so timings are indicative.
Bit-exactness does not depend on load.

Summary
-------
All reps are bit-exact with the fork reference (teststep, testcosmo) or
within float tolerance (SSE2 float teststep, max rel diff 0.000e+00).

Yield is (fork - ours) / fork using per-variant means. Positive means faster.

  AVX double:   teststep +19.1%, testcosmo +10.8%, restart +21.4%
  SSE2 double:  teststep  +6.1%, testcosmo  +0.6%, restart  +8.3%
  SSE2 float:   teststep +18.1%, testcosmo  +8.2%, restart +14.7%

Notes
-----
- Restart is one run per variant, so its yield is less reliable.
- The SSE2 double testcosmo gain is within the run-to-run spread of the
  fork (174 to 178 s), so it is effectively a tie.
- Round-4 numbers in ChaNGa_docs/RESULTS_HISTORY.md are five-run sums at
  mixed load. They are not per-run values and are not used here.
